# 시계열 분석 — 과제 1~6 기록

공간 4곳(강의실1·강의실2·회의실·라운지)의 CO₂·온도·습도로 앞으로 60분을 예측하고, 이상을 찾고, 상태를 추정했습니다.

> 모든 숫자는 연습 합성 데이터 기준입니다. 실제 키트 데이터로 다시 돌려 바꿀 예정입니다.

## 결과와 해석

| 과제 | 한 일 | 결과 | 해석 |
|---|---|---|---|
| 1 | 데이터 수집 | MQTT → InfluxDB 저장 | 나중에 쓸지 몰라 거르지 않고 전부 저장 |
| 2 | 기준선 | 현재값 유지 오차 67.4ppm | CO₂는 천천히 변하지만 수업 시작·끝에서 크게 틀림 |
| 3 | GRU 예측 | 39.1 → 일정 넣으면 25.3ppm | 일정이 "곧 사람이 온다"를 미리 알려 줌 |
| 4 | 이상 탐지 | 15건 중 13건 탐지, 헛경보 하루 0.72회 | 오토인코더와 규칙이 서로 못 잡는 고장을 채움 |
| 5 | 상태 추정 | 사용 여부 F1 0.869 → 0.942 | 지금 값보다 오르내리는 모양을 보면 더 잘 맞음 |
| 6 | 사전학습 모델 | Chronos-2 38.4 → 일정 넣으면 24.9ppm | 학습 없이 GRU만큼 맞지만 메모리를 약 1GB 더 씀 |

종합: 시계열 모델은 센서가 보여 주는 흐름은 잘 따라가지만, 사람이 언제 들어오고 나갈지는 센서만으로 알 수 없었습니다. 
일정 같은 바깥 정보를 넣었을 때 오차가 가장 크게 줄었고, 예약과 실제 사용이 자주 어긋나는 회의실이 끝까지 가장 어려웠습니다.
